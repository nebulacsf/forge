OpenRouter
Stored locally in ~/.forge/config.json.
Defaults
One round is one model call and may run several tools. BUILD checkpoints every “rounds per checkpoint” and stops at “rounds per turn”. Use 0 in the cost cap to disable it. PLAN has its own research budget: when it is reached, tools are disabled and Forge requires the final plan in up to three attempts, rejecting empty answers and tool calls written as text. Auto-continue applies to BUILD only. Older tool output is stubbed in place; only the most recent rounds are sent in full. Pruning every N rounds keeps the prompt prefix stable longer (better provider caching). Set a max to 0 to disable that cap.
Server
Host/port changes take effect after restarting Forge.
Logging
Records every request, model round, and tool call. Applies immediately. Also available as --debug or FORGE_DEBUG=1.
Extra verbose: logs the full request sent to the model (messages, tool schemas), every stream chunk, the response and its reasoning. Implies debug logging and writes prompt content to the log. Applies immediately. Also available as --debug-llm or FORGE_LLM_DEBUG=1.
