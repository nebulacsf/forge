Settings
Provider & credentials
How Forge authenticates with the model API. Used by every session and every model.
Stored locally in ~/.forge/config.json.
Model & mode
Starting point for new chats. Existing chats remember their own model and mode.
BUILD limits
One round is one model call, and a single round may run several tools.
PLAN research budget
Caps the research phase so a tool-hungry model cannot loop before writing the plan.
Tool limits
Per-call ceilings for the two tools that move the most text: file reads and shell commands.
Context & history
What gets pruned before each request. Older tool output is stubbed in place, so the conversation keeps its shape and the prompt prefix stays cacheable.
Local server
Where the web UI and the REST API listen. Changing host or port requires a restart.
Host/port changes take effect after restarting Forge.
Logging & diagnostics
Both switches apply immediately and are saved to the config file.
